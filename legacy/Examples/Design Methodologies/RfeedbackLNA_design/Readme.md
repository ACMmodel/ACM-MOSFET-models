# Design Methodology for Resistive-Feedback LNA using ACM2

>
> Work in progress
>
This repository provides scripts, documentation, and examples for the design of resistive-feedback low-noise amplifiers (R-feedback LNAs) using the Advanced Compact MOSFET Model 2 (ACM2).

The methodology exploits the normalized inversion-charge ($q_s$) formulation of ACM2 to support analytical exploration of key RF design trade-offs, including gain, noise figure, linearity, and input impedance matching, while reducing the dependence on time-consuming CAD-based design iterations.
